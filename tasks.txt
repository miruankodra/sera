[x] Task 3: Migrations

"Create all migrations for the schema defined in CLAUDE.md. Use the exact column names, types, nullable flags, indexes, and foreign key constraints shown. Respect the order: users → greenhouses → sensors → sensor_readings → devices → device_commands → automation_rules → alerts → tasks. [x] Task 4: Models, relationships, factories, seeders

"Create Eloquent models for all 9 tables with correct relationships, $fillable arrays, casts (including tasks.payload as array, recorded_at as datetime), and soft deletes on greenhouses and automation_rules. Phase 3 — Authentication
[x] Task 5: Auth endpoints

"Implement POST /api/v1/auth/register, POST /api/v1/auth/login, and POST /api/v1/auth/logout using Laravel Sanctum. Use FormRequests for validation. Return the token on login. Protect logout with auth:sanctum. Write Pest feature tests covering: successful register, successful login, invalid credentials (422), logout invalidates token. All tests must pass."


Phase 4 — Core API
[x] Task 6: Greenhouses CRUD

"Implement all greenhouse endpoints from CLAUDE.md. Create GreenhouseController, GreenhousePolicy (user can only access their own greenhouses), StoreGreenhouseRequest, UpdateGreenhouseRequest, and GreenhouseResource. Soft deletes must work. Write Pest feature tests covering: CRUD happy paths, 401 unauthenticated, 403 cross-user access. All tests must pass."

[x] Task 7: Sensors + readings

"Implement all sensor and sensor_reading endpoints. The POST /sensors/{id}/readings ingestion endpoint must fire a SensorReadingCreated event after saving (do not evaluate automation rules here — that happens in the queue). Add a composite index on (sensor_id, recorded_at). The GET readings endpoint must support ?from=&to= date range filtering. Write Pest tests. All tests must pass."

[x] Task 8: Devices + commands

"Implement all device endpoints plus POST /devices/{id}/command. The command endpoint must update devices.status and devices.last_commanded_at, create a row in device_commands with source = manual, and broadcast a DeviceStatusChanged event to the private greenhouse channel. Write Pest tests. All tests must pass."

[x] Task 9: Automation rules

"Implement automation rule endpoints. Create the AutomationEngine service class that accepts a SensorReading and evaluates all active rules for that greenhouse. Create the EvaluateAutomationRules job that calls AutomationEngine. Create the SensorReadingCreated event listener that dispatches this job to the Redis queue. When a rule triggers: create a device_command with source = automation, update device status, create an alert, and broadcast AutomationRuleTriggered and AlertFired events. Write Pest unit tests for AutomationEngine covering all operators (gt, lt, eq, gte, lte) and edge cases (no active rules, disabled device). All tests must pass."

[x] Task 10: Alerts + tasks

"Implement alert endpoints (GET /greenhouses/{id}/alerts, POST /alerts/{id}/read returns 204). Implement task endpoints (full CRUD). tasks.payload must be stored as JSON and cast to array on the model. Write Pest tests. All tests must pass."
